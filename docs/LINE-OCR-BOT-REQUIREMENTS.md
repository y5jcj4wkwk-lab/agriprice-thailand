# LINE OCR Bot — Requirements Draft

## ผู้ใช้งาน
บอทใน LINE ที่อ่านบิลขายผลผลิตทางการเข้าสรุป (handwritten), เช่นป่ายมือเขียนใน LINE แล้วไม่มีคนสรุป

## ปัญหานสำคัญ

- บิลขายผลผลิตทางการเข้าสรุป เช่นป่ายมือเขียน
- ตัวอย่างในกรณีไหน: ป่ายมือน้ำมัน (palm oil)
- บิลส่งเข้ามาส่งทุกวัน ไม่มีคนสรุปใน LINE

## ความต้องการ

1. ใช้ OCR อ่านรายมือเขียนในบิลให้ได้ข้อความข้อเข้าจากผู้ใช้งาน
2. สรุปข้อความจากบิลเป็น
   - วันที่ซื้อ (purchase date)
   - วันที่ขายของ (sale date)
   - ราคาต่อหน่วย (price per unit)
   - ขนาด (amount) ของเท่าไหน
3. ส่งผลลัพธ์สรุปกลับใน LINE

## สถานะที่กำลังไว้

- LINE Messaging API (webhook รับรูปและส่งข้อความ)
- OCR engine สำหรับรายมือเขียนไทย (เช่น Tesseract, Google Cloud Vision, หรือ Azure AI Document Intelligence)
- Backend สำหรับให้พารสรุปข้อความและประมวลผล

## สถานะต่อไป

- อัปเดตเพาะแพ็คเจ็จ Grok Bot แล้วให้สรุปอัตโโนมัติ
- เข้าโค้ดใน repo นี้ให้พร้อมใช้ได้เมื่อมี Grok Bot
