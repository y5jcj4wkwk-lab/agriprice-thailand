# Sports Streaming Aggregator — เว็บรวมลิงก์ถ่ายทอดสดกีฬาฟรี

> สร้างเมื่อ: 2026-11-18 | สถานะ: ไอเดีย ยังไม่ลงมือ | ต้นทุน: แทบศูนย์

## ปัญหา

- คนดูบอล/กีฬามากในไทย แต่ข้อมูลกระจัดกระจาย ต้องเสิร์ชเองทีละแมตช์
- บางทีเจอลิ้งก์พัง หรือไม่ฟรี
- ช่อง 7 / ช่อง 3 มีโปรแกรมกีฬาเยอะ (วอลเลย์บอล ฟุตบอล 7HD) แต่ไม่มีใครรวมตารางเป็นที่เดียว
- เวลาเปิดทีวีแล้วรู้ทีหลังว่าคู่ที่อยากดูกำลังแข่งอยู่แล้ว หรือพลาดไปแล้ว
- บอลต่างประเทศ (พรีเมียร์ลีก ฯลฯ) ดูฟรีได้ผ่านสตรีมมิ่งหรือยูทูบทางการ แต่ไม่มีที่รวม

## โซลูชัน

หน้าเดียว (one-page) ที่เปิดเช้ามาเห็น:
- บอลวันนี้แข่งกี่นัด
- แต่ละนัดดูได้ที่ไหน ฟรีหรือไม่ ภาษาไทยหรือไม่
- กีฬาไทย: วอลเลย์บอล ฟุตบอล ช่อง 7 / ช่อง 3 / 7HD
- กีฬาต่างประเทศ: พรีเมียร์ลีก และลีกอื่น ผ่านสตรีมมิ่งฟรีหรือยูทูบทางการ

## แหล่งข้อมูล (Data Sources)

1. **API กีฬาฟรี**
   - TheSportsDB — ตารางแมตช์ ผลบอล ช่องถ่ายทอด เป็น JSON
   - API-Football — ตาราง ผล คู่แข่ง ลีกต่างๆ
2. **ดึงจากเพจทางการ** ช่อง 7, ช่อง 3, ยูทูบทางการ แล้วใช้ AI อ่านสรุปเป็นตาราง
3. เป้าหมายระยะยาว: ดึงอัตโนมัติ ไม่ง้อคนขุดข้อมูล

## เทคนิค

- HTML/CSS/JS ธรรมดา (offline-first ตามสไตล์โปรเจกต์อื่น)
- โฮสติ้งถูกๆ หรือ GitHub Pages
- เริ่มจากหน้าเดียว: พรีเมียร์ลีก + บอลไทย + วอลเลย์บอล
- เพิ่มทีหลัง: ฟิลเตอร์ตามกีฬา ภาษา ฟรี/เสียเงิน

## โมเดลรายได้ (อนาคต)

- โฆษณา (Google AdSense)
- ยังไม่คิด เน้นทำใช้เองก่อน
