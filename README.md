# AgriPrice Thailand

เว็บไซต์ราคาพืชผลทางการเกษตรอย่างเป็นทางการของไทย — ข้าว ยางพารา ข้าวโพด ปาล์มน้ำมัน มันสำปะหลัง

## สถานะ

- โปรเจกต์นี้อยู่ในช่วงพัฒนา โครงสร้างพื้นฐาน (React + TanStack + Vite) พร้อมแล้ว
- ยังไม่มีหน้าแอปจริง โฟลเดอร์ `src/` กับ `server/` ว่างเปล่า
- มีสคริปต์ `scrape:prices` สำหรับดึงราคาพืชผล

## แผนถัดไป

- บอทอ่านบิลขายผลผลิต (ปาล์มน้ำมัน) ผ่าน LINE — ดูสเปกที่ `docs/LINE_BILL_BOT_SPEC.md`
- พัฒนาหน้าแสดงราคากับกราฟเทรนด์

## หมายเหตุ

- ข้อมูลการซื้อขายจริง (บิล ราคา ยอดขาย) **ไม่อยู่ใน repo นี้** — เก็บในฐานข้อมูลส่วนตัวของบอทเท่านั้น
- Repo นี้เป็นสาธารณะ เก็บได้เฉพาะโค้ดและเอกสาร
